# Microsoft Store release plan
Build on Windows x64 with BUILD.bat. For MSIX, reserve the product name in Partner Center, acquire the assigned identity and publisher, and package the full dist/Folder directory as a full-trust desktop application using Windows SDK tooling or MSIX Packaging Tool. Supply Store logo assets, privacy policy, accessibility and supported OS declarations. Do not submit a placeholder package. Test installation, update and uninstall in a clean Windows VM and run Windows App Certification Kit. Disable arbitrary registry changes in the Store edition; use supported package manifest declarations for any approved shell integration. Optional default folder handling is not implemented. Store eligibility and name availability are not guaranteed. Review Qt LGPL distribution obligations and dependency notices before publishing.
