# Roadmap
- 0.2: thumbnail gallery, navigation tree, image preview, registry context menu, extension API (implemented; runtime validation pending).
- 0.3: native Windows Shell thumbnails for PDF/video/Office, virtual locations, favorites persistence, system clipboard and drag/drop, cancellable file operations and progress.
- 0.4: configurable columns, grouping, tags, folder icons, archive browsing, accessible keyboard navigation and wallpaper rendering behind content.
- 0.5: signed installer, safe uninstall, optional default directory handler research with explicit rollback and Windows compatibility testing. Never replace explorer.exe or Winlogon shell.
- 1.0: automated integration tests, stable plugin API, performance benchmarks, localization and signed releases.
